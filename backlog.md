## Goal

Ship a Metro component library for Compose Multiplatform that a person who used a Lumia recognises
as Metro rather than as a Metro-coloured Material application — and ship it as a core that depends
on no Material artefact, with interop as a second, optional one.

The order of work follows what can invalidate what. Three questions can each redefine the
architecture, and two of them can change the public API, so nothing is estimated until they are
answered. After that the order is: the token layer everything reads, the press feedback everything
inherits, the components that prove the tokens are right, and only then the navigation and the
adapter that make it a release.

## Decisions worth not re-litigating

**Nothing is estimated before stage 0 closes.**
Every size in stage 1 assumes that tilt is automatic ([B-01](docs/backlog/B-01-spike-tilt-indication.md)),
that the Pivot numbers exist ([B-02](docs/backlog/B-02-spike-pivot-metrics.md)), and that Cyrillic
has a home ([B-03](docs/backlog/B-03-spike-cyrillic-font.md)). Two of the three change the shape of
the public API if they land badly, and an estimate made on top of an unresolved API is a number with
nothing behind it.

**The Material version question is a build task, not a research task.**
[B-04](docs/backlog/B-04-repository-skeleton.md) carries it because it can only be settled by
resolving the dependency graph: there is no stable Material 3 in the Compose Multiplatform 1.12 line,
and which of the two workable pairs actually compiles is a fact about Gradle rather than about POM
text ([research §1.2](docs/research/research-architecture.md)).

**Icons stay off the critical path on purpose.**
[B-18](docs/backlog/B-18-icon-set.md) is a designer-week that is routinely planned as a programmer-
afternoon, and nothing in the first release depends on it: the bar draws the circle and takes a
`content` slot.

**An invented number ships as a parameter, never as a fact.**
Where Microsoft published nothing — the Pivot header, the live-tile flip interval, the Panorama
parallax — this project's value goes into the public API with a KDoc sentence saying whose number it
is. That rule is what keeps [B-02](docs/backlog/B-02-spike-pivot-metrics.md) from turning a failed
spike into a silent fiction.
