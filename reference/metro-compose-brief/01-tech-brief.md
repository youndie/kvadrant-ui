# Metro UI для Compose Multiplatform — технический бриф

**Что делаем:** библиотеку компонентов в дизайн-языке Metro (Windows Phone 8 / Windows 8) для Compose Multiplatform, с отдельным слоем-адаптером, позволяющим сосуществовать с `androidx.compose.material3`.

**Дата:** 26 августа 2026 · **Статус:** pre-implementation research

---

## 1. Резюме

Ниша практически свободна. Единственный предшественник — `louis993546/Metro-Compose` (9 звёзд, только Android, в Maven не публикуется, MIT). Fluent-нишу занял `compose-fluent-ui` (727★, Apache-2.0, полноценный CMP), но это другой дизайн-язык, и `Pivot` там не реализован. **Ни одна Windows-библиотека для Compose не имеет моста к Material** — прецедента для нашего адаптера в Windows-мире нет.

Материала для точной реализации достаточно: тайминги моушна, формулы tilt-эффекта, цветовые токены обеих тем, обе типографические рампы, метрики плиток и большинства контролов извлечены из первоисточников Microsoft и лежат в `02-metro-spec.md` с пометками достоверности. Восемь пробелов остались — главный из них метрики `Pivot`, которых Microsoft не публиковал вообще.

Три вещи определяют, получится проект или нет:

1. **`TiltIndication`** — воспроизведение WP-наклона на текущем `IndicationNodeFactory`. Технически путь открыт, практически не проверен.
2. **Метрики `Pivot`** — снимаются только реверсом `Microsoft.Phone.dll`.
3. **Шрифт для кириллицы** — Selawik, единственная легальная метрически совместимая замена Segoe, **кириллицы не содержит**.

Ни одно из трёх не является тупиком, но все три должны быть закрыты до того, как имеет смысл оценивать сроки. Отсюда фаза 0 — две недели спайков.

## 2. Почему это не «просто перекрасить Material»

Metro — не стилистический вариант Material, а конфликтующая с ним система. Точки, где они расходятся структурно:

| | Material 3 | Metro |
|---|---|---|
| Форма | скруглённые `Shape`, от `extraSmall` до `extraLarge` | **всё прямоугольное**, `RectangleShape` везде |
| Глубина | elevation + tonal surface (цвет поверхности зависит от высоты) | **плоскость**, глубины нет вообще |
| Отклик на нажатие | ripple из точки касания | **tilt** — 3D-наклон плоскости к точке касания |
| Фон тёмной темы | `surface` ≈ `#1C1B1F` | **абсолютный `#000000`** |
| Цветовая модель | 48 ролей, тональные палитры, гармонизация | **13 токенов + один акцент** |
| Типографика | 15 стилей `display…label`, единый вес | 12 стилей, **вес задаётся выбором семейства**, не числом |
| Иерархия | размер + вес + цвет | **преимущественно размер**, разброс 18.667 → 186.667 px |
| Диалоги | безопасное действие справа | **позитивное действие слева** (в Win8 — наоборот, чем в WP) |

Отдельно: light-тема Metro **не является инверсией dark**. Foreground = 87 % чёрного (а не 100 % белого), subtle = 40 % (против 60 %), disabled = 30 % (против 40 %). Механическая инверсия даёт «почти Metro» — и это первое, что заметит человек, который держал в руках Lumia.

Из-за этого из ~22 компонентов Material3 примерно **4 переживают решейп одной темой, ~10 требуют обёртки, ~11 — полной замены**. Детальная таблица с причинами — `04-architecture.md` §7.

## 3. Архитектура в двух абзацах

**Ядро** (`metro-core`) не зависит от Material вообще — только `compose.foundation`. Тема устроена по канону, отработанному в Material3 и `compose-fluent-ui`: `@Immutable data class` для `MetroColors` / `MetroTypography` / `MetroMetrics` / `MetroMotion`, `staticCompositionLocalOf` с рабочими дефолтами, `internal`-локалы и публичный объект-аксессор `MetroTheme.colors` с `@Composable @ReadOnlyComposable` геттерами. Плюс отдельная `MetroThemeConfiguration` для точечного override в поддереве — приём из `compose-fluent-ui`, разводящий тяжёлый корень и лёгкий scoped-override.

**Адаптер** (`metro-material-adapter`) — отдельный артефакт, стратегия B: композабл `MetroMaterialAdapter { }`, который читает текущую `MetroTheme` и поднимает над ней `MaterialTheme` с производной `ColorScheme` (ключевой приём — `surfaceTint = Color.Transparent`, он убивает тональные поверхности), `Typography` из WP-рампы и `Shapes`, где все шесть значений — `RectangleShape`. Ripple глушится через `LocalRippleConfiguration provides null` и заменяется на `LocalIndication provides TiltIndication`. Обратный адаптер `MetroTheme.fromMaterial()` — для встраивания Metro-компонентов в существующее Material-приложение. Модель «два лямбда-слота + `AdaptiveWidget`» взята у `compose-cupertino` — единственного работающего прецедента второй дизайн-системы в KMP.

Три поправки к ходовым заблуждениям, которые стоит запомнить:

- Win8 Title — **SemiBold**, не Bold. Caption 12 px = **9 pt**, не 12 pt.
- Нажатие в tilt-эффекте **не анимируется** — свойства ставятся мгновенно, анимируется только возврат. И `Scale` там не используется вообще, только `PlaneProjection`.
- ContextMenu **не блюрит** фон — он масштабирует его 1.0 → 0.94 за 420 мс. Блюра в исходниках нет.

## 5. Риски

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| `IndicationNodeFactory` не тянет layout-модификацию на практике | средняя | **высокое** — tilt это подпись Metro | спайк 1; план Б — явный `Modifier.metroTilt()` |
| Метрики Pivot не удаётся снять | средняя | высокое | спайк 2; план Б — наша интерпретация, честно помеченная |
| Кириллица: разный ритм Selawik и Inter | **высокая** | среднее | спайк 3; решение фиксируется до старта |
| M3 1.5 остаётся в alpha, DSL меняется | высокая | среднее | ядро без Material; адаптер отдельным артефактом с `strictly`-диапазоном; две ветки |
| Скриншот-тесты на не-Android таргетах | средняя | среднее | Roborazzi (экспериментально); официального решения для CMP нет |
| `abiValidation` меняет DSL (Kotlin 2.4, `@ExperimentalAbiValidation`) | средняя | низкое | `@OptIn` + готовность мигрировать |
| Иконки: ~40 глифов с нуля | высокая | среднее | в v0.1 слот `content` вместо готового набора |
| Конфликт «аутентичность vs a11y» (тач 25.5 dp, контраст акцентов) | **высокая** | среднее | политика: визуал канона + расширенные хит-области всегда, контраст opt-in |

## 7. Двенадцать решений, которые нужно принять

Полная таблица с вариантами и рекомендациями — `06-roadmap.md`. Пять самых важных:

1. **Шрифт для кириллицы.** Selawik + Inter в fallback (быстро, разный ритм) или только Inter (единый ритм, но вся числовая рампа поедет, потому что метрики не сегоевские). → спайк 3.
2. **Множитель px → dp = 0.75.** Подтверждается тремя независимыми проверками: 20 px = 15 sp = 15 pt; 32 px = 24 dp = высота статус-бара Android; вся Win8-рампа даёт ровно официальные пункты. → принять как канон.
3. **Стратегия интеропа.** B — отдельный `MetroMaterialAdapter { }` + сахар `MetroMaterialTheme`, C (обратный) как дополнение. Не A: ядро не должно тащить Material.
4. **Аутентичность vs доступность.** Визуал канона, хит-области всегда расширенные до 48 dp, контрастный режим — opt-in.
5. **Объём v0.1.** Если спайк 2 (Pivot) провалится — урезать до 10 контролов и плиток, Pivot переносится в 0.2.
