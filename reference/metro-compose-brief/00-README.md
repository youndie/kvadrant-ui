# Metro UI для Compose Multiplatform — пакет технического брифинга

Материалы для принятия решения о разработке библиотеки компонентов в дизайн-языке Metro (Windows Phone 8 / Windows 8) для Compose Multiplatform, с адаптером под `androidx.compose.material3`.

Собрано 26 августа 2026.

---

## С чего начать

**Читать в этом порядке:**

1. **`01-tech-brief.md`** — главный документ. Резюме, почему это не «перекрасить Material», архитектура в двух абзацах, риски, сроки, 12 открытых решений. *(~15 мин)*
2. **`06-roadmap.md`** — фазы, три спайка фазы 0, таблица решений с рекомендациями, статус верификации. *(~10 мин)*
3. **`05-component-catalog.md`** — 55 компонентов с оценкой сложности и приоритетом. *(~10 мин)*

**Справочники, читать по мере надобности:**

4. **`02-metro-spec.md`** — числовая спецификация Metro. Источник истины для токенов. Каждое число помечено `✅` (первоисточник Microsoft), `🟡` (выведено) или `❌` (публичного источника нет).
5. **`03-existing-solutions.md`** — аудит существующих библиотек, что легально переиспользовать, шрифтовой вопрос.
6. **`04-architecture.md`** — архитектура `MetroTheme` с полными Kotlin-листингами: модель темы, `TiltIndication` на `IndicationNodeFactory`, таблицы маппинга на `ColorScheme`/`Typography`/`Shapes`, три стратегии интеропа, gradle-модули, тестирование.

`references/*.svg` открываются в браузере и в любом векторном редакторе. Размеры и зазоры на схемах соблюдены точно — их можно мерить.

`references/metro-tokens.json` — готовый вход для генератора Kotlin-констант: цвета обеих тем, 20 акцентов с посчитанной luminance и контрастом, обе типографические рампы, метрики, плитки, тайминги и кривые моушна, формулы tilt.

## Три вывода, если читать нечего времени

1. **Ниша свободна.** Единственный предшественник для Compose — `Metro-Compose` (9★, только Android, не публикуется, MIT). Fluent-нишу занял `compose-fluent-ui`, но это другой дизайн-язык. Моста к Material нет ни у кого.

2. **Материала для точной реализации достаточно.** Цветовые токены, обе типографические рампы, метрики плиток, тайминги моушна и формулы tilt извлечены из первоисточников Microsoft. Восемь пробелов, главный — метрики `Pivot`, которых Microsoft не публиковал вообще.

3. **Три риска решают судьбу проекта, и все три снимаются за две недели спайков:** воспроизводимость tilt-эффекта на `IndicationNodeFactory`, метрики `Pivot` (реверс `Microsoft.Phone.dll`), и шрифт — **в Selawik нет кириллицы**.

## О достоверности

Всё, что здесь есть, собрано из первоисточников: архивные страницы MSDN на `learn.microsoft.com/previous-versions`, официальные PDF UX guidelines Microsoft, исходники Microsoft на GitHub (`WindowsPhoneToolkit`, `WinJS`), дампы `ThemeResources.xaml` из WP SDK, исходники сторонних библиотек.

Числа, которые Microsoft публиковал только картинкой (палитра акцентов) или которые выведены арифметически (зазоры между плитками), помечены отдельно. Числа, которых не существует в публичном доступе, названы прямо — вместе с тем, как их добыть.

Отдельно зафиксированы **подтверждённые отсутствия** — вещи, которых нет и не было, хотя интернет утверждает обратное: тайминги переворота live-плиток («cannot be controlled by apps»), пороги жестов WP, блюр в ContextMenu.
